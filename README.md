# ArenaBook - Online Sports Venue Reservation System

ArenaBook is a web-based application developed using Python and Django that allows users to search and reserve sports venues and turfs online conveniently. 

The main objective of this project is to provide a centralized and user-friendly platform for sports venue reservation, handling everything from browsing available turfs to managing mock financial transactions.

## 🚀 Features

* **Dynamic Venue Discovery:** Users can explore available sports grounds based on location and sport type.
* **Instant Search Filtering:** Client-side JavaScript filtering allows users to instantly search for venues by name or city.
* **Secure User Authentication:** Custom session-based login and logout functionality for tracking user-specific reservations.
* **Booking Management:** Users can schedule bookings for specific dates and time slots, which automatically calculates the total hourly cost.
* **Mock Checkout Gateway:** A dedicated secure checkout UI that processes simulated payments and updates booking statuses.
* **User Dashboard:** A personalized "My Bookings" page where users can view their reservation history and payment statuses.
* **Comprehensive Admin Panel:** Administrators can efficiently manage venues, bookings, payments, and customer reviews through a customized Django backend dashboard.

## 🛠️ Technology Stack

* **Backend:** Python, Django 6.0
* **Database:** SQLite
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Architecture:** MVT (Model-View-Template)
